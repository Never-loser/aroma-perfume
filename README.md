# 👑 Aroma — قالب فروشگاهی پریمیوم عطر

لوکس‌ترین و کامل‌ترین قالب فروشگاه آنلاین عطر و ادکلن، ساخته‌شده با **React 19 + TypeScript + Tailwind CSS 4**. کاملاً راست‌چین، واکنش‌گرا و آماده‌ی فروش.

---

## ✨ ویژگی‌ها

- **۲۶+ صفحه و پنل** (خانه، فروشگاه، تک‌محصول، سبد، تسویه‌حساب، حساب کاربری، مقالات، ۴۰۴ و...)
- **روتینگ مبتنی بر URL** (همگام‌سازی آدرس + Back/Forward + Deep-link)
- **سه چیدمان مستقل** برای صفحه‌های کلیدی (کلاسیک / مدرن / مجله‌ای)
- **پنل کاربری کامل** (سفارش‌ها، علاقه‌مندی، تیکت، آدرس‌ها، نشست‌ها، کیف پول، امنیت)
- **احراز هویت**: ایمیل/رمز + ثبت‌نام + فراموشی رمز + **ورود با موبایل (OTP)**
- **دستیار هوشمند عطر** (چت‌بات توصیه‌گر)
- **دارک / لایت مود**
- **۶ فونت فارسی** قابل‌تعویض (ایران‌یکنان، وزیرمتن، کتیبه، لاله‌زار، مرکزی، نوتو)
- **مقایسه‌ی محصولات**، **علاقه‌مندی**، **سریچ هوشمند**
- **اسکلتون لودینگ**، **بنر کوکی**، **SEO + JSON-LD**
- کاملاً **واکنش‌گرا (Mobile First)** از ۳۲۰px تا ۱۹۲۰px

## 🚀 نصب و اجرا

```bash
npm install
npm run dev      # سرور توسعه
npm run build    # نسخه‌ی تولید
npm run preview  # پیش‌نمایش نسخه‌ی تولید
```

---

## 📁 ساختار پروژه

```
src/
├── components/      کامپوننت‌های UI و صفحات
├── data/           داده‌ی محصولات و مقالات
├── hooks/          هوک‌های سفارشی (useLoading, useSEO)
├── store/          مدیریت وضعیت سراسری + روتر
└── index.css       سیستم طراحی (توکن‌ها، رنگ، تایپوگرافی)
```

---

## 🎨 سیستم طراحی

از CSS Variables و Design Tokens استفاده شده است. برای تغییر رنگ‌بندی، متغیرهای `:root` در `src/index.css` را ویرایش کنید.
